# CLAUDE.md — document-extraction-lab

## What this is
The owner's public lab for getting data out of documents. Each topic lives in
its own folder under `topics/` with its own README, samples and results.
Topics are added over time; the repo is not tied to one method.

First topic: `topics/glyph-table/` — PDFs whose text cannot be extracted
(characters drawn as shapes, or fonts with no Unicode information). A
generative AI drafts a glyph→character table once, a human checks it, and
every run after that is a plain lookup: free, offline, the same every time,
nothing invented. Includes a comparison with a generative-AI API and notes
from trying related OSS projects.
